# Source Selection

This document records the sections selected from each source document for the initial RAG corpus.

## Selection Principles

- Prefer sections containing substantive business, policy, compliance, or governance information.
- Preserve original document terminology.
- Preserve original page numbers where available.
- Avoid duplicate or highly repetitive content.
- Keep enough context around selected sections for meaningful retrieval.
- Retain source metadata for citation and evaluation.
